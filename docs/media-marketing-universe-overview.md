## 5. Community ID — field schema (no live PII)

**UNPUBLISHED. Schema only.** Placeholder formats below. Do not publish live member names, photos, government IDs, phone numbers, or addresses in this repo.

| Field | Type | Example format only | Notes |
|---|---|---|---|
| display_name | string | `[DISPLAY NAME]` | Marketing card face; not a legal ID |
| aka | string | `[AKA]` | Optional |
| member_id | string | `HHP-NC-PITT-######` | Pattern only; no live numbers here |
| city_region | string | `Greenville, NC` | Region label |
| role_labels | string[] | `advocate`, `creator`, … | **Engagement labels** — not clinical titles |
| member_since | year | `YYYY` | Year only |
| qr_cta | enum | `Scan · Connect · Build` | Concept CTA |
| photo | media ref | `[PLACEHOLDER PORTRAIT]` | Never store live portraits in public GitHub |
| partner_marks | string[] | `T2F Media`, `MAEG` | Back-of-card themes |

**Back-of-card themes (UNPUBLISHED):** community-owned ecosystem; Identity | Opportunity | Impact; Learn | Create | Earn | Build | Belong.

**Control:** Community ID / People’s Pass must not be described as employment, investment, governance share, cash-redeemable value, or a live token balance.
